# 图形界面版（GUI）

面向**不编写代码**的用户，也是默认使用的版本。

## 目录内容

```text
03_GUI/
|-- README.md
`-- nanoamp.exe          图形界面程序（约 10 MB，双击即可运行）
```

## 安装

**推荐方式：双击 `../install.exe`。** 它会把界面装到
`%LOCALAPPDATA%\nanoamp\app\nanoamp.exe`，并在桌面创建
**「nanoamp 分析工具」** 快捷方式。

安装完成后双击桌面图标即可使用。

## 不安装直接运行的用法（前提：已完成安装）

如果已经执行过一次 `install.exe`（R 和依赖均已就位），
直接双击本目录下的 `nanoamp.exe` 也能打开窗口。

> `nanoamp.exe` 只包含界面本身（约 10 MB），**不含 R 运行时**。
> R 和 109 个依赖包由 `install.exe` 安装。这样处理的代价是需要先装 R，
> 收益是安装包体积小、启动快。

### 操作步骤

1. **测序文件**：选择公司提供的 `.fastq`。
   若同目录下有 `reference.self.fa`，选择 fastq 后会自动填上参考。
2. **目的序列**：选择 `.fa` / `.fasta` 文件。
3. **输出目录**：默认 `我的文档\nanoamp 结果`，通常不需要修改。
4. **模式**：保持 `A - 参考引导（推荐）`。**显示前 n 条** 保持 20。
5. **功能注释（可选）**：需要判断变异会不会改变蛋白时，勾选「功能注释…」，
   再选一条路线并填参数（见下文「功能注释（可选）」）。不需要就跳过这一步。
   在线路线建议先点 **「列出转录本」**，把结果填进 **转录本** 下拉框后再分析。
6. 点 **「开始分析」**，等状态栏显示"分析完成"。

### 六个标签页

| 标签 | 内容 |
|---|---|
| **单倍型结果** | 核心结果表。选中某行，下方显示该序列完整碱基 |
| **注释结果** | 每个「单倍型 × 转录本」一行的后果；顶部状态行说明本次覆盖了哪些转录本（仅启用注释时有内容） |
| **变异注释** | 每个变异一行的后果，含 CDS 坐标、密码子与氨基酸变化（仅启用注释且勾选「输出变异级明细」时有内容） |
| **QC 指标** | reads 数、比对率、平均一致度等质量指标 |
| **输出文件** | 本次生成的文件，双击用系统默认程序打开 |
| **运行日志** | R 的实时输出，出错时查看此处 |

### 按钮

| 按钮 | 作用 |
|---|---|
| **开始分析** | 启动分析（后台线程执行，窗口不会卡死） |
| **环境自检** | 跑 `nanoamp doctor`，把 R / 依赖 / minimap2 / curl / 缓存目录 / 配置目录 / 注释可用性的状态写进日志 |
| **复制诊断信息** | 把运行日志（含「环境自检」全部输出）复制到剪贴板，方便反馈问题 |
| **列出转录本** | 仅在线路线可用：先查一次扩增子重叠的转录本，结果写进日志并填进「转录本」下拉框 |
| **刷新 / 清空缓存** | 显示缓存目录、文件数与占用；清空只删可重新下载的参考数据 |
| **测试 Ensembl 连接** | 现在能不能访问 Ensembl；不可用时状态行直接说明，离线 CDS 路线不受影响 |
| **查看蛋白序列…** | 打开可滚动、可复制的窗口显示选中行的参考/突变蛋白（需勾选「输出蛋白序列」重跑） |
| **打开输出目录** | 在资源管理器里打开结果文件夹 |

### 高级参数（可选）

勾选「模式」那一行的 **「高级参数…」** 才会出现，用来改比对方式（`minimap2` / `r`）、
线程数、各阈值（最小支持 reads、最小频率、最小一致度、最小覆盖、聚类一致度、
最小簇 reads、簇共识）以及是否保留 BAM。

**只有改动过的字段才会传给命令行**，所以勾上但不动任何值 = 什么都没发生；填了非法值
（非数字、频率不在 0–1）会在起跑前弹窗提示。「恢复默认值」一键复位。

### 注释结果与单倍型的联动

在「单倍型结果」里选中一行，「注释结果」和「变异注释」两页会自动只显示该单倍型
（标注行写明「仅显示 Hn（K / N 行）」），点「显示全部」恢复；反过来在注释页选一行，
也会选中单倍型表里对应的行。

## 功能注释（可选）

勾选输入区的 **「功能注释…」** 后，程序会把每条单倍型的变异翻译成生物学后果
（移码 / 提前终止 / 终止丢失 / 整码插入缺失 / 错义 / 同义，以及 UTR、内含子、剪接区），
并多写两个文件：

| 文件 | 内容 |
|---|---|
| `annotation.tsv` | 每个「单倍型 × 转录本」一行，含中英双列后果、蛋白变化、转录本冲突标记 |
| `variants_annotation.tsv` | 每个变异一行，含 CDS 坐标、密码子与氨基酸变化（勾选「输出变异级明细」时才有） |

**不勾选「功能注释…」时，输出与以前逐字节一致**（有测试锁定这一点）。

两条路线在界面里直接选：

| 配置来源 | 需要联网 | 你要填什么 |
|---|---|---|
| **离线 CDS（不联网）**（默认） | 否 | CDS 的起止坐标、链与读码框。坐标以**目的序列**为准（1-based，两端都算），长度必须是 3 的倍数 |
| **在线 genome（需联网，用 Ensembl）** | 是 | 什么都不用填：程序自行在 GRCh38 定位扩增子并从 Ensembl 取转录本结构。建议先点「列出转录本」确认能定位，并在下拉框里指定转录本（默认 `自动选择（MANE / 规范）`） |
| **自定义 JSON…** | 看文件内容 | 点「浏览…」指定一个注释配置 JSON |

界面会即时校验离线路线的参数：填完起止坐标后，提示行显示
`离线 CDS 路线：不联网。CDS 长度 120 bp（40 个密码子）。`；
长度不是 3 的倍数时直接给出
`CDS 长度 121 bp 不是 3 的倍数，注释会被跳过（应删掉 1 bp 或调整读码框）。`

**模式 C 不执行注释**：勾了注释又选模式 C 时会弹窗说明注释参数被忽略 ——
模式 C 只做原始精确匹配统计，没有校正后的序列可以翻译。

判断注释覆盖了哪些转录本，请看「注释结果」页的状态行与 `qc.tsv` 的
`n_transcripts_annotated` / `n_transcripts_skipped` / `annotation_skip_reason`，
**不要只看 `annotation.tsv` 有几行**。注释被跳过时**退出码仍是 0**（序列分析本身是成功的），
但原因会写进输出文件，不会悄悄变成"成功"。

> 注释**不新增任何 R 依赖包**；在线路线需要系统里有 `curl.exe`（Windows 10 1803 起自带）。
> 参考序列切片缓存在 `%LOCALAPPDATA%\nanoamp\cache\ref`；缓存与网络相关开关
> （`--cache-dir` / `--no-cache` / `--clear-cache`）见
> [`../02_CLI/README.md`](../02_CLI/README.md)。

## 结果解读

「单倍型结果」表的列含义：

| 列 | 含义 |
|---|---|
| 排名 | 按 reads 数从多到少 |
| 编号 | H1、H2… 每种不同序列的编号 |
| **reads 数** | 支持这条序列的 reads 条数 |
| **占比** | 占全部 reads 的百分比 ← 主要关注数值 |
| **是否与目的序列一致** | `是` = 和目的序列完全一样 |
| SNV / 插入 / 缺失 | 相对目的序列有几处变异 |
| 变异 | 具体描述，如 `218delG` = 第 218 位少一个 G |
| 长度 | 序列碱基数 |

**读法示例：**

```text
排名  编号  reads 数  占比     是否一致   变异
 1    H1     142    33.3%     否       218delG
 2    H2     134    31.5%     是       .
 3    H3     114    26.8%     否       218delG;135C>T
```

→ 该样本中 **31.5% 是目的序列**；最多的一种（33.3%）少了一个 G；
第三多的（26.8%）同时少一个 G 且有一个 C→T 突变。

> 选中某一行若显示"未导出序列"，原因是 `haplotypes.fasta` 只保存前 n 条
> （默认 20 条）。把「显示前 n 条」调大后重新运行即可。

## 故障排查

**双击没反应 / 一闪而过**
说明 R 或依赖未装好。先执行一次 `../install.exe` 完成安装。

**提示找不到 R**
`%LOCALAPPDATA%\nanoamp\config.ini` 里的 `rscript=` 指向的路径失效了。
重新运行 `install.exe`。

**分析失败**
查看「运行日志」标签页最后几行。最常见原因是
①相应文件被占用，②输出目录没有写权限，③输入 FASTQ 格式不对。

**中文路径出错**
输入/输出路径尽量用英文且不含空格，例如 `D:\nanoamp_data\`。

**结果里几乎没有"是否一致 = 是"**
先看「QC 指标」的 `n_reads_total`：低于 50 条时比例不可靠。
其次确认目的序列选择正确（本样本的预期序列，不是别的样本的）。

**「注释结果」页显示"注释不可用"**
注释被跳过，**不是分析失败**。原因写在状态行上，同一原因也记录在 `qc.tsv` 的
`annotation_skip_reason`：CDS 长度不是 3 的倍数、坐标填错、或在线路线取不到数据。

**勾了「功能注释…」却没有注释产物**
确认模式不是 C（模式 C 不执行注释），并确认「配置来源」选对了路线。

## 技术说明（给开发者）

- 界面用 **Python + Tkinter**：Tkinter 随 CPython 提供，无运行时依赖，
  冻结后只有约 10 MB（对比 PySide6 会到 100 MB 以上）。
- **不重写任何算法**：界面通过子进程调用 R 的 `nanoamp_cli()`，
  与命令行完全一致，因此两者结果不可能不一致。
- 打包：`python 02_code/PythonGUI/build_exe.py`（PyInstaller，one-file、windowed）。
- 功能注释的界面部分只生成一个临时配置 JSON 并转交给 `--annotate-config`：
  算法、输出与命令行完全同一份实现。注释**不引入新的 R 依赖**，
  在线路线只依赖系统 `curl.exe`。
- 安装后由 `%LOCALAPPDATA%\nanoamp\config.ini` 的 `home=` 告知数据目录位置。
- 源码与打包细节见 `02_code/PythonGUI/README.md`。
